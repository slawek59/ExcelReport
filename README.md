# Excel Report Generator

## Opis

Program pobiera dane z wielu plików Excel,
łączy je i generuje raport końcowy.

## Instalacja

pip install -r requirements.txt

## Uruchomienie

python main.py

## Wynik

Program tworzy:

output/final_report.xlsx

## Technologie

- Python
- Pandas
- OpenPyXL
- XlsxWriter
